# stm32-charging-monitor · 基于 STM32 的智能充电监控显示系统

> 本科毕业设计（在研中）。仓库随开发进度持续更新，**只写真实完成的内容**。
> 目标：把毕设从"交一份论文"做成"一个可以开源、可以演示、经得起追问的完整项目"。

## 项目简介

设计并实现一套电池充电监控系统：STM32 作为主控，实时采集充电电压 / 电流，
根据采样值判定充电状态（待机 / 快充 / 涓流 / 满电），并通过显示模块可视化呈现，
超出安全阈值时进行告警。

## 系统方案（随设计深化持续修订）

```
┌────────────────────────── STM32 主控 ──────────────────────────┐
│                                                                │
│  ADC 多通道采样 ──► 电压/电流换算 ──► 充电状态机 ──► 显示刷新      │
│   (分压电阻测压)      (换算/滤波)      (状态判定)     (OLED/LCD)   │
│                                            │                   │
│  安全阈值监测 ◄─────────────────────────────┘                   │
│   (过压/过流 → 告警)                                             │
└────────────────────────────────────────────────────────────────┘
```
