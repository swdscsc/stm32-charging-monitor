# firmware/ 固件代码目录

代码按模块推进后上传，规划如下（完成一个模块提交一个 commit）：

- `00-led-blink/`    —— 工程模板跑通（时钟、下载、串口 printf）
- `01-adc-sample/`   —— ADC 单通道采样，串口打印原始值
- `02-voltage-conv/` —— 分压换算 + 均值滤波，输出真实电压
- `03-current/`      —— 电流采样
- `04-state-machine/`—— 充电状态机
- `05-display/`      —— 显示模块
- `main/`            —— 最终整合版

每个模块目录内附一个简短 README：功能、接线、验证方法、预期现象。

> 注意：只上传自己写的、验证过的代码。直接抄的例程要注明出处，
> 模板生成文件（如 CubeMX 生成的工程框架）不用删，但核心逻辑必须能讲清楚。
